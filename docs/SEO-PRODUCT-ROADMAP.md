# SEO and Product Roadmap

This roadmap prioritizes durable organic growth over publishing a large number of thin pages. New work should be selected from Search Console demand, user feedback, internal-search data, competitor gaps, and scientific curriculum needs.

## Priority 0: production prerequisites

1. Configure the canonical production origin in `NEXT_PUBLIC_SITE_URL`.
2. Add and verify Google Search Console and Bing Webmaster Tools ownership.
3. Submit the XML sitemap and monitor indexing, canonical selection, rich-result eligibility, and crawl errors.
4. Configure privacy-respecting analytics and Web Vitals collection.
5. Add a real project or business contact method and keep privacy, terms, editorial, and correction policies accurate.
6. Add an explicit repository license only after the owner chooses the intended reuse terms.

## Priority 1: improve existing pages before expanding

- Review Search Console queries and optimize pages with impressions but weak click-through rate.
- Strengthen introductions, worked examples, definitions, assumptions, unit guidance, error states, and related-tool links.
- Add visible reviewed or updated dates only when backed by a genuine editorial review workflow.
- Build subject hubs for chemistry, mechanics, electricity, measurement, uncertainty, and data analysis.
- Add contextual links between calculators, formula pages, report guidance, and templates.
- Consolidate overlapping pages rather than allowing keyword cannibalization.
- Create a correction and scientific-review process with named reviewer credentials where available.

## Priority 2: high-value product features

Add these only when demand and maintenance capacity justify them:

- Calculator search with subject, formula, variable, and unit filters
- Save, print, or export calculation results without requiring an account
- Shareable calculation links that exclude sensitive or unnecessary data
- Classroom worksheet mode with answer-key generation
- Unit-aware input validation and clearer dimensional-analysis explanations
- Related formulas, prerequisite concepts, and common-mistake guidance
- Accessible copy-result and print layouts
- Optional offline or installable PWA support after measuring repeat usage

## Candidate calculator clusters

Validate search intent and overlap before implementation.

### Chemistry

- Beer-Lambert law and absorbance
- Buffer and Henderson-Hasselbalch calculations
- Titration and equivalence-point calculations
- Reaction rate and rate constants
- Equilibrium constant and reaction quotient
- Solubility and Ksp
- Calorimetry and heat capacity
- Nernst equation and electrochemistry

### Physics

- Work, energy, and efficiency
- Torque and rotational motion
- Centripetal force and circular motion
- Wave speed, frequency, and wavelength
- Lens and mirror equations
- Electric field, Coulomb force, and capacitance
- Series and parallel circuit analysis
- Thermal expansion and heat transfer

### Laboratory and data analysis

- Confidence intervals
- Standard error
- Relative percent difference
- Calibration-curve interpolation
- Serial dilution planner
- Significant-figure operation rules
- Outlier screening with clearly stated limitations
- Measurement repeatability and reproducibility summaries

## Content opportunities

- Complete practical guides tied to real tasks, not generic glossary pages
- Worked examples for common school and introductory university experiments
- Safety and disposal links to authoritative institutional sources, without replacing local laboratory rules
- Teacher resources mapped to curriculum topics where accurate mapping can be maintained
- Formula pages that explain assumptions, units, rearrangements, and calculator links
- Comparison guides only where users genuinely need help choosing a method or formula

## Safe-removal policy

Do not delete a route, component, dependency, or asset merely because it appears unused in one search. Before removal:

1. Search imports, dynamic references, route registries, tests, scripts, metadata, and public URLs.
2. Check analytics, backlinks, Search Console performance, and indexed URL status.
3. Redirect any retired URL to the closest genuine replacement when one exists; otherwise return an appropriate gone or not-found response.
4. Update sitemaps, navigation, internal links, tests, and documentation.
5. Run the complete quality pipeline and compare the production output.

## Avoid

- Mass-generated calculator pages with near-identical explanations
- FAQ schema on content that is not visibly presented or eligible
- Keyword stuffing, hidden text, doorway pages, or city and country variants without local value
- Unsupported claims such as “most accurate” or “expert reviewed”
- Adding AI chat merely for novelty; it needs a bounded educational use case, trustworthy sourcing, privacy controls, and ongoing evaluation
- Publishing medical, hazardous-chemical, or advanced laboratory guidance without qualified review and clear safety boundaries

## Measurement framework

Track outcomes by page cluster rather than raw page count:

- Valid indexed pages and canonical consistency
- Non-branded clicks, impressions, and average position
- Click-through rate by query and page
- Engaged sessions and successful calculator completions
- Internal-search refinements and zero-result searches
- Core Web Vitals by page type
- Backlinks and citations to genuinely useful resources
- Content corrections, test failures, and support feedback

Review the roadmap quarterly. Promote ideas only when evidence shows user value, ranking opportunity, scientific reliability, and sustainable maintenance.
